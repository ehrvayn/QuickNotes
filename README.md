# QuickNotes

A fast and secure note management application built with a modern full-stack architecture.

## Features

- **Fast & Responsive** - Lightning-quick note creation and retrieval
- **Secure** - JWT-based authentication with encrypted passwords
- **Clean UI** - Intuitive interface for seamless note management
- **RESTful API** - Well-structured backend API for reliable data handling

## Tech Stack

### Frontend
- React 18
- TypeScript
- Tailwind CSS
- Axios for API calls

### Backend
- Node.js + Express
- TypeScript
- PostgreSQL
- JWT Authentication

## Getting Started

### Prerequisites
- Node.js (v16+)
- PostgreSQL
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/yourusername/quicknotes.git
cd quicknotes
```

2. Setup Backend
```bash
cd Back-end
npm install
```

3. Create `.env` file in Back-end folder
